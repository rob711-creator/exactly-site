# Exactly — support & privacy pages

The two pages Google Play and the App Store require as live URLs for the game
**Exactly: Number Puzzle**.

- `index.html` — support & contact page (Apple requires a live Support URL)
- `privacy.html` — privacy policy (Google requires a live Privacy Policy URL)

Served by GitHub Pages. This repo is public only because free Pages requires it;
the game's source lives elsewhere and stays private.

No fonts, no analytics, no third-party requests — a privacy policy that loaded a
tracker would be answering its own question.
